01

命名总流程

先定类别，再选母体；先编号，再写名字
定类别最高优先级官能团
→
选母体含主官能团的最长链/环
→
编号主官能团位次最小
→
写前缀其余基团、先简后繁
→
加构型顺反、Z/E、R/S

先问三句话

  1. 谁最高？分子里优先级最高的官能团是谁？
  2. 谁最长？含主官能团的最长链/环是哪一条？
  3. 谁最小？怎样编号让主官能团位次最小？

三句话答完，名称的骨架就出来了；剩下的只是取代基和标点。

名称解剖

2-甲基-1-丙醇

  • 2-甲基：2 号碳上有一个甲基
  • 1-：—OH 在 1 号碳
  • 丙醇：母体是 3 碳的醇

结构：HOCH2CH(CH3)CH3。名称中的每个数字都要能落到结构上。

三类名字

层次例子用途
俗名酒精、醋酸、石炭酸生活/历史
习惯名正丁烷、邻二甲苯教材/考试
系统名2-甲基丙烷正式作答

这本手册怎么用

  • 查：按页眉编号找“优先级、母体、各官能团”表格。
  • 记：只看口诀、流程和易错清单，不背长段解释。
  • 考：考前看第 12—14 节：40 条易错、真题速查、30 分钟清单。
总口诀：先定类别后选链，主官能团聚优先；近简小定编号，先简后繁写在前；数字逗号字短横，构型符号放最前。

优先级口诀：羧、磺、酐、酯；酰卤、酰胺、腈；醛、酮、醇、酚；硫、胺、醚；卤、硝最后。前面的作母体，后面的作前缀。

选母体四条规则

  1. 主官能团最多：二元酸优先选含两个 —COOH 的链。
  2. 碳链最长：数目相同，选最长链；环状选最大环。
  3. 重键最多：仍有选择时，选 C=C/C≡C 最多的链。
  4. 取代基最多：最后选支链最多的链，名称更简洁。

苯环：母体还是侧链？

  • 主官能团直接连苯环：苯环作母体。例：苯酚、苯甲醛、苯甲酸、苯磺酸。
  • 主官能团在侧链：侧链作母体。例：苯甲醇、苯乙酸、3-苯基丙酸。
  • 只有烷基/卤/硝基/烷氧基：通常苯环作母体。例：甲苯、氯苯、硝基苯、苯甲醚。
三个“不是”：卤素不是母体；硝基不是母体；醚键不是后缀。它们永远作前缀。

烷烃与环烷烃

长、多、近、简、小；环上顺反看平面

习惯命名

碳数12345678910
名甲乙丙丁戊己庚辛壬癸

10 以上用汉字数字：十一烷、十二烷。正/异/新只用于习惯名。

系统命名五步

  1. 选最长链为母体；等长选取代基最多。
  2. 从离支链最近的一端编号。
  3. 同近时，简单基团优先（甲基先于乙基）。
  4. 同近同简，位次组逐项比较，先小者优。
  5. 写名称：先简后繁，相同合并，数字逗号、数字汉字短横。

环烷烃

  • 以环为母体：环某烷；单取代不写位次。
  • 编号沿环，使取代基位次组最小。
  • 两个相同取代基：邻 1,2-、间 1,3-、对 1,4-。
  • 顺反相对于环平面：同侧顺，异侧反。

桥环 / 螺环

双环[a.b.c]：总碳数 = a+b+c+2；a≥b≥c。

螺[a.b]：总碳数 = a+b+1；小环在前。

例：双环[2.2.1]庚烷（7 碳）；螺[4.5]癸烷（10 碳）。高中只需认得格式。

04

烯烃与炔烃

主链含重键；编号让重键位次最小

烯烃四步

  1. 选含 C=C 的最长链；多条时选双键最多。
  2. 从靠近双键的一端编号，使双键位次最小。
  3. 双键位次写在“烯”前；丁烯起不能省。
  4. 其余基团作前缀，先简后繁。

例：3-甲基-1-丁烯；2-甲基-2-丁烯；2-乙基-1-丁烯。

二烯与环烯

  • 二烯：母体“二烯”，位次全写。例：1,3-丁二烯。
  • 异戊二烯系统名：2-甲基-1,3-丁二烯。
  • 环烯：双键占 1、2 位，沿双键编号。
  • 例：1-甲基环己烯、3-甲基环己烯。

炔烃

  • 选含 C≡C 的最长链，称为“某炔”。
  • 从靠近三键一端编号，三键位次最小。
  • 乙炔、丙炔可省位次；丁炔起必须写。
  • 例：1-丁炔、2-丁炔、1,3-丁二炔。

烯炔

  • 主链同时含 C=C 和 C≡C，取重键最多。
  • 编号让重键位次组最小；并列时先烯后炔。
  • 名称：先“烯”后“炔”。
  • 例：1-丁烯-3-炔。

芳香烃

苯环编号、邻间对、侧链母体

一个取代基

苯为母体，不写位次：甲苯、乙苯、氯苯、硝基苯、苯酚、苯胺。

两个相同取代基

邻 1,2-；间 1,3-；对 1,4-。例：邻二甲苯、间二甲苯、对二甲苯。

三个相同取代基

连 1,2,3-；偏 1,2,4-；均 1,3,5-。例：连三甲苯、偏三甲苯、均三甲苯。

06

卤代烃·醇酚醚

卤素作前缀；—OH 连在哪决定醇还是酚

卤代烃

  • 卤素永远作前缀，不作母体。
  • 母体是烷/烯/苯；编号先满足母体位次。
  • 例：溴乙烷、2-溴丙烷、1,2-二溴乙烷、氯苯、3-氯-1-丙烯。
  • 卤素与 —OH/—COOH 共存：卤素作前缀。例：2-氯乙醇、2-氯丙酸。

醇

  • 选含 —OH 的最长链，从靠近 —OH 一端编号。
  • 多元醇：乙二醇、丙三醇（甘油）。
  • 例：2-丙醇、2-甲基-1-丙醇、2-甲基-2-丙醇。

酚

  • —OH 直接连苯环；以苯酚为母体，—OH 为 1 位。
  • 邻甲酚 = 2-甲基苯酚；间甲酚 = 3-；对甲酚 = 4-。
  • 间苯二酚 = 1,3-苯二酚；苦味酸 = 2,4,6-三硝基苯酚。

醚

  • 习惯名：某醚（二甲醚、甲乙醚、乙醚）。
  • 系统名：烷氧基某烷（甲氧基乙烷、1-甲氧基丙烷）。
  • 苯甲醚 = 甲氧基苯。
  • 有 —OH 时：2-甲氧基乙醇，不能叫“2-羟基乙甲醚”。

3-丁醇2-丁醇—OH 位次未取最小

07

醛酮·羧酸衍生物

醛基碳为 1 位；酯名“酸 + 醇 + 酯”

醛

  • —CHO 碳固定为 1 位；从它开始编号。
  • 例：甲醛、乙醛、丙醛、2-甲基丙醛、丙烯醛、苯甲醛。
  • 二元醛：乙二醛（OHC—CHO）。
  • 醛作前缀：甲酰基。

酮

  • 选含 C=O 的最长链，编号让羰基位次最小。
  • 例：丙酮、2-丁酮、3-戊酮、苯乙酮、环己酮。
  • 酮作前缀：氧代。例：4-氧代戊酸、3-氧代丁醛。
  • 醛优先于酮：—CHO 作母体。

羧酸

  • —COOH 碳为 1 位；二元酸用“某二酸”。
  • 例：甲酸、乙酸、丙酸、2-甲基丙酸、乙二酸、己二酸、苯甲酸、丙烯酸。
  • 羟基酸：2-羟基丙酸（乳酸）、2-羟基丁二酸（苹果酸）。

酯

  • 某酸 + 某醇 + 酯；酸名在前，醇名在后。
  • 例：甲酸甲酯、乙酸乙酯、丙酸乙酯、苯甲酸甲酯、乙酸苯酯。
  • 二元酯：乙二酸二乙酯、丁二酸二甲酯。
  • 不能写成“乙二酸乙二酯”“二丁酸二甲酯”。

酰胺 / 酰卤 / 酸酐

  • 酰胺：酸名改“酰胺”。乙酰胺、苯甲酰胺、N-甲基乙酰胺、尿素。
  • 酰卤：乙酰氯、苯甲酰氯。
  • 酸酐：乙酸酐。

腈

  • —CN 碳为 1 位，计入主链。
  • 例：乙腈、丙腈、丙烯腈、苯甲腈、2-甲基-2-丙烯腈。
高频错：4-酮戊酸 → 4-氧代戊酸；3-丁酮 → 2-丁酮；乙酸乙酯 ≠ 乙酯乙酸；N-甲基乙酰胺 ≠ 2-甲基乙酰胺。

含氮含硫·多官能团

胺、硝基、磺酸、硫醇；真实分子降维

胺

  • 简单胺：烃基 + 胺。甲胺、二甲胺、三甲胺。
  • 芳香胺：苯胺；N-甲基苯胺（甲基连 N）。
  • N- 表示连在氮上，不是碳链 2 位。

硝基

  • —NO2 永远作前缀：硝基甲烷、硝基苯、2-硝基甲苯。
  • TNT = 2,4,6-三硝基甲苯；苦味酸 = 2,4,6-三硝基苯酚。
  • 硝基 —NO2 ≠ 硝酸酯 —ONO2。硝化甘油 = 丙三醇三硝酸酯。

磺酸

  • —SO3H 作后缀“磺酸”，优先级仅次于羧酸。
  • 例：甲磺酸、苯磺酸、对甲苯磺酸、4-氯苯磺酸。

硫醇 / 硫醚

  • —SH 作后缀“硫醇”：乙硫醇。
  • —S— 作“硫醚”：二甲硫醚。
  • 与醇/醚对应，只需把 O 换成 S。
多官能团五步：圈官能团 → 排优先级 → 选母体 → 编号 → 写前缀。例：HOCH2CH2COOH = 3-羟基丙酸；CH3COCH2CH2COOH = 4-氧代戊酸；H2NCH2CH2OH = 2-氨基乙醇。

09

顺反与 Z/E

相同基看顺反，较优基看 Z/E

有没有顺反？

  • 旋转受限：C=C 或环。
  • 双键每个碳都连两个不同基团。
  • 只要有一个碳连两个相同基团，就没有顺反。
  • 例：2-丁烯有；2-甲基-2-丁烯无。

Z/E 三步

  1. 每个双键碳上，按次序规则选较优基团。
  2. 较优基团在同侧为 Z，异侧为 E。
  3. 四个基团都不同也能用；顺/反此时不够用。

10

手性碳与 R/S

四个不同基团；最小基团朝后

手性碳

  • 一个 sp3 碳连四个互不相同的基团。
  • 例：2-丁醇、丙氨酸的 α 碳。
  • 有手性碳不一定旋光：内消旋体有对称面。

R/S 四步

  1. 确认四个基团互不相同。
  2. 按次序规则排序 1＞2＞3＞4。
  3. 把 4 号基团放在远离观察者的方向。
  4. 1→2→3 顺时针 R，逆时针 S。

Fischer 投影式

  • 横线朝前，竖线朝后。
  • 最小基团在横线：判断后反转；在竖线：直接判断。
  • D-甘油醛 = R；L-丙氨酸 = S。
  • D/L 是相对构型，不等于 +/- 旋光方向。

外消旋 / 内消旋

  • 外消旋体：R/S 等量混合物，宏观不旋光。
  • 内消旋体：分子内有对称面，单一化合物，不旋光。
  • 酒石酸：RR、SS、RS（内消旋）三种。
易错：有手性碳 ≠ 一定旋光；D 型 ≠ 一定右旋；L-丙氨酸是 S，不是 R。

考前 30 分钟

六步自检 + 一张口袋卡

六步自检

  1. 主官能团：选的是不是优先级最高的？
  2. 母体：主链含主官能团吗？最长/最多吗？
  3. 编号：主官能团位次最小吗？再重键、再取代基？
  4. 取代基：相同合并？不同“先简后繁”？
  5. 书写：逗号、短横、括号用对了吗？
  6. 立体：顺/反、Z/E、R/S 需要吗？

最后看一眼

  • 醛基碳一定是 1 位；羧基碳一定是 1 位。
  • 卤素、硝基永远作前缀。
  • 酯名：酸在前，醇在后。
  • 苯环有主官能团时，主官能团所在碳为 1 位。
  • 顺式不一定 Z；D 型不一定右旋。
总口诀：先定类别后选链，主官能团聚优先；近简小编号，先简后繁写在前；数字逗号字短横，构型符号放最前。

有机命名 · 口袋卡
