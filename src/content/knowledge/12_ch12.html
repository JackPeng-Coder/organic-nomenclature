CHAPTER 12 · ALCOHOLS, PHENOLS, ETHERS

醇、酚、醚的命名

醇和酚都含 —OH，区别在于 —OH 连在侧链还是苯环上；醚则是“氧原子夹在两个烃基之间”。把“谁连在谁身上”看清楚，名字就不会混。

12.1　醇的命名

醇命名四步
  1. 选含 —OH 碳的最长碳链为母体，称为“某醇”。
  2. 从靠近 —OH 的一端编号，使 —OH 位次最小。
  3. —OH 作后缀；其余基团作前缀，按“先简后繁”排列。
  4. 多元醇用二、三表示 —OH 个数，并写出每个 —OH 的位次。

{{ fig('1propanol', '1-丙醇', 'xsmall') }}

{{ fig('2propanol', '2-丙醇', 'xsmall') }}

读法：从靠近 —OH 的一端编号：1-丙醇的 —OH 在端点，2-丙醇的 —OH 在中间碳。两者互为位置异构。

读法：2-甲基-1-丙醇是异丁醇；2-甲基-2-丙醇是叔丁醇。两者主链都是丙醇，区别在 —OH 和甲基的位置。
例 12-3　多元醇POLYOL
{{ fig('ethyleneglycol', '乙二醇（1,2-乙二醇）', 'xsmall') }}
乙二醇
{{ fig('glycerol', '丙三醇（甘油）', 'xsmall') }}
丙三醇
读法：乙二醇的主链是乙烷，两个 —OH 分别在 1、2 位；丙三醇的主链是丙烷，三个 —OH 在 1、2、3 位。高中常用俗名“甘油”，系统名要写“丙三醇”。
醇的编号不能让 —OH 位次变大

例如 CH3CH(OH)CH2CH3 是 2-丁醇，不是 3-丁醇。编号必须从靠近 —OH 的一端开始；若两端等距，再让取代基位次最小。

12.2　酚的命名

—OH 直接连在苯环上，属于酚。以苯酚为母体，—OH 所在环碳为 1 位，其他取代基按最低位次组编号。

{{ fig('phenol', '苯酚', 'xsmall') }}
苯酚
{{ fig('ocresol', '邻甲酚（2-甲基苯酚）', 'xsmall') }}

例 12-5　苯二酚与硝基苯酚PHENOL

C6H4(OH)2：两个 —OH 在苯环上，按位置分为邻、间、对苯二酚。

间苯二酚的系统名是 1,3-苯二酚。

2,4,6-三硝基苯酚俗称苦味酸；—OH 为 1 位，三个硝基在 2、4、6 位。

{{ fig('resorcinol', '间苯二酚（1,3-苯二酚）', 'small') }}
酚 ≠ 醇

苯酚不是“苯甲醇”。苯酚的 —OH 直接连苯环；苯甲醇的 —OH 连在侧链 CH2 上，属于醇。两者的性质和命名都不同。

12.3　醚的命名

醚是 R—O—R′。高中常用两种命名法：

习惯命名：某醚

两个烃基名称 + “醚”。相同的烃基合并，如二甲醚、二乙醚；不同的烃基按“先简后繁”，如甲乙醚。

系统命名：烷氧基某烷

把较小的烃基与 O 组成“烷氧基”，较大的烃基作母体烷。如甲氧基乙烷、乙氧基乙烷。

{{ fig('diethylether', '乙醚（乙氧基乙烷）', 'xsmall') }}
乙醚
{{ fig('anisole', '苯甲醚（甲氧基苯）', 'xsmall') }}
苯甲醚
{{ fig('2methoxypropane', '2-甲氧基丙烷', 'xsmall') }}
2-甲氧基丙烷
读法：乙醚的系统名是乙氧基乙烷；苯甲醚的系统名是甲氧基苯；2-甲氧基丙烷的母体是丙烷，甲氧基在 2 位。
例 12-7　甲乙醚与 1-甲氧基丙烷ETHER

CH3OCH2CH3：习惯名“甲乙醚”；系统名“甲氧基乙烷”。

CH3OCH2CH2CH3：习惯名“甲丙醚”；系统名“1-甲氧基丙烷”。

系统命名时，选择较长的烃基作母体，较短的烃基与 O 组成烷氧基。

12.4　醇酚醚共存

当分子中同时有 —OH 和醚键时，—OH 的优先级更高，醚键作“烷氧基”前缀。例如 CH3OCH2CH2OH 是 2-甲氧基乙醇，不是“2-羟基乙甲醚”。

例 12-8　2-甲氧基乙醇PRIORITY

母体是乙醇：—OH 所在碳为 1 位，甲氧基在 2 位。

2-甲氧基乙醇

醚键不作后缀；只有没有更高优先级官能团时，才用“某醚”命名。

2-羟基乙甲醚2-甲氧基乙醇—OH 优先级高于醚键，应作母体。
醇酚醚的“三看”
  • 看 —OH 连在哪：侧链是醇，苯环是酚。
  • 看碳链：含 —OH 的最长链；多元醇让 —OH 数目最多。
  • 看醚键：有更高官能团时作“烷氧基”前缀；否则用“某醚”或“烷氧基某烷”。
