CHAPTER 14 · CARBOXYLIC ACIDS AND DERIVATIVES

羧酸及其衍生物的命名

羧酸是官能团优先级里的“最高一档”。它作母体时，羧基碳就是 1 号碳；它作取代基时，名称变成“羧基”。酯、酰胺、酰卤、酸酐、腈，都可以看作羧酸的“变体”。

14.1　羧酸的命名

羧酸命名四步
  1. 选含 —COOH 碳的最长碳链为母体，称为“某酸”。
  2. —COOH 的碳固定为 1 位；二元酸从一端编到另一端，两个 —COOH 碳都在主链内。
  3. 其余基团作前缀；—COOH 作取代基时写“羧基”。
  4. 二元酸用“某二酸”，两个羧基的位次通常不需写（除非有取代基需要定位）。

{{ fig('aceticacid', '乙酸', 'xsmall') }}

读法：甲酸 HCOOH、乙酸 CH3COOH、丙酸 CH3CH2COOH。羧基碳都算在主链内，且为 1 位。

例 14-3　苯甲酸与丙烯酸NAME
{{ fig('benzoicacid', '苯甲酸', 'xsmall') }}

{{ fig('acrylicacid', '丙烯酸', 'xsmall') }}

{{ fig('salicylicacid', '2-羟基苯甲酸（水杨酸）', 'xsmall') }}

读法：苯甲酸的 —COOH 直接连苯环；丙烯酸含 C=C，母体是丙烯酸；水杨酸的 —OH 在苯环 2 位，系统名 2-羟基苯甲酸。

羧酸分子中羧基数目不同，名称也不同：一元酸用“某酸”，二元酸用“某二酸”，三元酸用“某三酸”。例如 HOOC—CH2—COOH 是丙二酸，HOOC—(CH2)4—COOH 是己二酸。

14.2　酯的命名

酯：某酸某酯

酯是羧酸与醇（或酚）脱水形成的。命名时把“酸”和“醇”的名字拼起来：酸名 + 醇名 + 酯。例如乙酸与乙醇形成的酯叫“乙酸乙酯”。

  • 酸名在前，醇名在后，不能颠倒。
  • 二元酸与两分子醇形成的酯，用“某二酸二某酯”。
  • 醇是酚时，写“某酸苯酯”等。

读法：乙二酸二甲酯是 CH3OOC—COOCH3；丁二酸二甲酯是 CH3OOC—CH2CH2—COOCH3。不要写成“二丁酸二甲酯”或“丁二酸甲二酯”。
酯名不能“酸醇颠倒”

乙酸乙酯 ≠ 乙酸乙酸酯。命名时先写酸的部分，再写醇的部分。若酯基中的 —COO— 方向画反，结构就变成了另一种酯。

14.3　酰胺的命名

酰胺是羧酸中的 —OH 被 —NH2（或取代氨基）替换得到的。命名时把羧酸名称的“酸”改为“酰胺”：

结构名称说明
HCONH2甲酰胺甲酸的酰胺
CH3CONH2乙酰胺乙酸的酰胺
C6H5CONH2苯甲酰胺苯甲酸的酰胺
CH3CONHCH3N-甲基乙酰胺甲基连在 N 上
H2NCONH2尿素（碳酰胺）碳酸的二酰胺
例 14-7　乙酰胺与 N-甲基乙酰胺AMIDE
{{ fig('acetamide', '乙酰胺', 'xsmall') }}
乙酰胺
{{ fig('nmethylacetamide', 'N-甲基乙酰胺', 'xsmall') }}

{{ fig('urea', '尿素（碳酰胺）', 'xsmall') }}
尿素
读法：N-甲基乙酰胺中，甲基连在氮上，不是连在碳上；尿素是碳酸的二酰胺，系统名“碳酰胺”。

14.4　酰卤、酸酐与腈

酰卤：某酰卤

羧酸中的 —OH 被卤素替换。如 CH3COCl 乙酰氯，C6H5COCl 苯甲酰氯。

酸酐：某酸酐

两分子羧酸脱水。如 (CH3CO)2O 乙酸酐；一元酸酐用“某酸酐”。

腈：某腈

—C≡N 的碳计入主链并作 1 位。如 CH3CN 乙腈，CH2=CHCN 丙烯腈。

{{ fig('acetylchloride', '乙酰氯', 'xsmall') }}

{{ fig('aceticanhydride', '乙酸酐', 'xsmall') }}

{{ fig('acrylonitrile', '丙烯腈', 'xsmall') }}

读法：乙酰氯是 CH3COCl；乙酸酐是两分子乙酸脱去一分子水；丙烯腈含 C=C 和 —CN，—CN 的碳为 1 位。

14.5　例析与易错

错误名称正确名称错因
乙二酸二乙酯（写成乙二酸乙二酯）乙二酸二乙酯两个醇分子，用“二乙酯”，不是“乙二酯”。
二丁酸二甲酯丁二酸二甲酯酸名与醇名位置颠倒，且“二丁酸”不存在。
乙酸乙酯（写成乙酯乙酸）乙酸乙酯酯名顺序固定为“酸 + 醇 + 酯”。
1-羧基乙烷丙酸羧基碳应计入主链；主链 3 碳。
2-甲基丙酸（写成 3-甲基丙酸）2-甲基丙酸羧基碳为 1 位，甲基只能在 2 位。
N-甲基乙酰胺（写成 2-甲基乙酰胺）N-甲基乙酰胺甲基连在 N 上，不是连在碳链 2 位。
3-丙烯腈（把氰基画在 3 位）丙烯腈—CN 碳为 1 位，双键只能在 2 位。
羧酸衍生物的“母体链”
  • 羧酸：—COOH 碳为 1 位；二元酸两端都是羧基碳。
  • 酯：酸名在前、醇名在后；二元酯用“二某酯”。
  • 酰胺：酸名改“酰胺”；N-取代写在名称前。
  • 腈：—CN 碳为 1 位，主链含氰基碳。
