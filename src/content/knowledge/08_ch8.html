CHAPTER 08 · AROMATIC COMPOUNDS

芳香烃的命名

苯环是一个“六边形的舞台”：取代基在环上的位置，用 1,2,3… 或邻、间、对、连、偏、均来标记。苯环上如果有主官能团，母体可能是苯环；如果主官能团在侧链，母体也可能变成侧链。

8.1　苯与单环芳烃

苯 C6H6 是最简单的芳香烃。苯环上的一元取代物，通常以苯为母体，称为“某苯”：

结构名称说明
C6H5CH3甲苯甲基苯；系统名也作甲基苯
C6H5CH2CH3乙苯乙基苯
C6H5CH2CH2CH3丙苯正丙基苯
C6H5CH(CH3)2异丙苯枯烯；系统名 2-苯基丙烷
C6H5CH=CH2苯乙烯乙烯基苯；重要单体
C6H5C≡CH苯乙炔乙炔基苯

苯

苯环上的氢被其他基团取代时，若只有一个取代基，不必写位次；有两个或更多取代基，才需要编号或用邻、间、对等标记。

8.2　苯的同系物：邻间对、连偏均

苯环上有两个相同取代基时，相对位置有三种：

邻（1,2-）

两个取代基在相邻碳上。习惯名“邻二甲苯”，系统名“1,2-二甲苯”。

间（1,3-）

两个取代基相隔一个碳。习惯名“间二甲苯”，系统名“1,3-二甲苯”。

对（1,4-）

两个取代基相对。习惯名“对二甲苯”，系统名“1,4-二甲苯”。

{{ fig('oxylene', '邻二甲苯（1,2-二甲苯）', 'small') }}
邻二甲苯
{{ fig('mxylene', '间二甲苯（1,3-二甲苯）', 'small') }}
间二甲苯
{{ fig('pxylene', '对二甲苯（1,4-二甲苯）', 'small') }}

三个相同取代基时，用“连、偏、均”：

位置1,2,3-1,2,4-1,3,5-
习惯名连三甲苯偏三甲苯均三甲苯
系统名1,2,3-三甲苯1,2,4-三甲苯1,3,5-三甲苯
“1,3,4-三甲苯”是错误编号

三个甲基在环上，若编号得到 1,3,4，应重新选择 1 位，使位次组变为 1,2,4。系统命名要取最低位次组；不要看到“1,3,4”就以为可以。

8.3　多取代苯的编号

多取代苯编号四步
  1. 定主官能团：若环上有 —COOH、—SO3H、—CHO、—OH、—NH2 等主官能团，以其所在碳为 1 位。
  2. 无主官能团时：选一个取代基为 1 位，使所有取代基位次组最小。
  3. 位次组比较：逐项比较，先小者为优；不要只看位次之和。
  4. 并列时：高中写法让较简单取代基位次更小；2017 规则按英文首字母顺序。
例 8-3　2,6-二氯甲苯NAME

母体是甲苯，甲基所在碳为 1 位；两个氯在 2、6 位。

2,6-二氯甲苯

若以氯为 1 位，位次组会变成 1,2,6 或 1,3,4，不如 1,2,6 与甲基的 1 位组合；以甲基为 1 位最简洁。

苯甲酸的羧基碳不参与苯环编号，羧基所在环碳为 1 位。

8.4　侧链官能团与母体选择

苯环上连有官能团时，母体不一定是苯环。判断的关键是：主官能团直接连在苯环上，还是连在侧链上？

结构名称母体选择
C6H5OH苯酚—OH 直接连苯环，苯环为母体
C6H5CH2OH苯甲醇—OH 在侧链，甲醇为母体，苯基为取代基
C6H5CHO苯甲醛—CHO 直接连苯环，苯环为母体
C6H5COOH苯甲酸—COOH 直接连苯环，苯环为母体
C6H5CH2COOH苯乙酸—COOH 在侧链，乙酸为母体，苯基为取代基
C6H5COCH3苯乙酮羰基直接连苯环，苯乙酮为常用名
C6H5NH2苯胺—NH2 直接连苯环，苯环为母体
例 8-6　苯甲醇、苯甲醛、苯甲酸PARENT
{{ fig('benzylalcohol', '苯甲醇', 'xsmall') }}
苯甲醇
{{ fig('benzaldehyde', '苯甲醛', 'xsmall') }}
苯甲醛
{{ fig('benzoicacid', '苯甲酸', 'xsmall') }}
苯甲酸
读法：—OH 在侧链，母体是甲醇；—CHO、—COOH 直接连苯环，母体是苯环。若把苯甲醇写成“苯酚的甲基取代物”，就混淆了官能团的位置。
例 8-7　苯乙酸与 3-苯基丙酸PARENT

C6H5CH2COOH：羧基在侧链，母体是乙酸，苯基在 2 位，习惯名“苯乙酸”。

C6H5CH2CH2COOH：母体是丙酸，苯基在 3 位，名“3-苯基丙酸”。

8.5　苯乙烯、苯乙炔与联苯

苯环与不饱和侧链相连时，高中常用“苯乙烯”“苯乙炔”这样的习惯名；系统名可看作“乙烯基苯”“乙炔基苯”。命名时注意：双键/三键在侧链上，苯环作为取代基“苯基”。

例 8-8　苯乙烯与苯乙炔NAME
{{ fig('styrene', '苯乙烯', 'small') }}
苯乙烯
{{ fig('phenylacetylene', '苯乙炔', 'small') }}
苯乙炔

两个苯环直接相连叫联苯；两个苯环通过一个亚甲基相连叫二苯甲烷；通过一个羰基相连叫二苯甲酮。这些名字在高考中偶尔出现，认得即可。

结构名称说明
C6H5—C6H5联苯两个苯环直接相连
C6H5—CH2—C6H5二苯甲烷两个苯环夹一个 CH2
C6H5—CO—C6H5二苯甲酮两个苯环夹一个羰基

8.6　稠环芳烃简介

两个或多个苯环共用边，叫稠环芳烃。高中常见的是萘、蒽、菲。萘的编号是固定的：从一个桥头碳相邻的位置开始，沿环编号 1—8，桥头碳为 4a、8a。

例 8-9　萘与 1-甲基萘FUSED RING
{{ fig('naphthalene', '萘', 'small') }}
萘
{{ fig('1methylnaphthalene', '1-甲基萘', 'small') }}
1-甲基萘
读法：萘环上有两种不同的位置：1,4,5,8 位（α 位）和 2,3,6,7 位（β 位）。1-甲基萘与 2-甲基萘是不同异构体。

蒽和菲的编号更复杂，高中只需识别结构、知道名称，不需要在普通命名题中给它们编号。竞赛或强基会进一步要求。

例 8-10　2,4,6-三硝基甲苯（TNT）NAME

母体甲苯，甲基为 1 位；三个硝基在 2、4、6 位。

2,4,6-三硝基甲苯

TNT 是俗名/缩写；系统名不能写成“三硝基甲苯”，位次不能省。

例 8-11　2,4,6-三硝基苯酚（苦味酸）NAME

母体苯酚，—OH 为 1 位；三个硝基在 2、4、6 位。

2,4,6-三硝基苯酚

俗称苦味酸；注意与 TNT 区分：前者母体是苯酚，后者母体是甲苯。

错误名称正确名称错因
1,3,4-三甲苯1,2,4-三甲苯未取最低位次组；应重新编号。
2-氯-1-甲苯2-氯甲苯（或邻氯甲苯）甲苯为母体，甲基固定 1 位，氯写 2 位即可；不要写“1-甲苯”。
苯甲醇（写成苯酚）苯甲醇—OH 在侧链，不是直接连苯环。
苯甲酸（写成苯乙酸）苯甲酸羧基直接连苯环；苯乙酸多一个 CH2。
2,4,6-三硝基苯酚（写成 2,4,6-三硝基甲苯）2,4,6-三硝基苯酚母体不同：苯酚 vs 甲苯。
1-甲基-2-氯苯2-氯甲苯母体是甲苯，甲基为 1 位，不必再写“1-甲基”。
芳香命名的“三问”
  • 主官能团直接连苯环，还是在侧链？决定母体是苯环还是侧链。
  • 环上取代基的位次组是否最小？并列时是否按“先简后繁”？
  • 两个取代基是否可用邻/间/对？三个相同取代基是否可用连/偏/均？
