CHAPTER 06 · ALKENES

烯烃的命名

烯烃命名只比烷烃多一条硬规则：主链必须包含双键的两个碳，编号必须让双键位次最小。剩下的，仍然是“选母体、编号、写取代基”的老流程。

6.1　主链与编号

烯烃系统命名四步
  1. 选主链：选含 C=C 两个碳的最长碳链；若有多条，选双键数目最多的一条。
  2. 编号：从靠近双键的一端开始，使双键位次最小；若两端相同，再使取代基位次最小。
  3. 写取代基：双键以外的基团作前缀；相同基合并，先简后繁。
  4. 写母体：“某烯”，双键位次写在“烯”前；只有一种位置时也不能省略位次（乙烯、丙烯除外）。
例 6-1　1-丁烯与 2-丁烯NAME
{{ fig('1butene', '1-丁烯：双键在 1 位', 'small') }}
1-丁烯
{{ fig('3methyl1butene', '3-甲基-1-丁烯', 'small') }}
3-甲基-1-丁烯
读法：主链 4 个碳，双键在 1 位；若从另一端编号，双键会变成 3 位，显然不是最低位次。

注意：3-甲基-1-丁烯 不能写成“2-甲基-3-丁烯”。后者的双键位次更大，而且主链方向也选错了。

双键位次不能省

乙烯、丙烯只有一种双键位置，可以省略位次；从丁烯开始，必须写清 1- 或 2-。例如 CH3CH=CHCH3 是 2-丁烯，不是“丁烯”。

6.2　多烯与烯基

含两个双键的烃叫二烯烃，母体用“二烯”；双键位次全部写出，用逗号隔开。例如：

例 6-2　1,3-丁二烯与异戊二烯DIENE
{{ fig('13butadiene', '1,3-丁二烯', 'small') }}
1,3-丁二烯
{{ fig('isoprene', '2-甲基-1,3-丁二烯（异戊二烯）', 'small') }}
2-甲基-1,3-丁二烯
读法：主链 4 个碳，两个双键分别在 1、3 位；2 号碳上有一个甲基。异戊二烯是习惯名，系统名要写“2-甲基-1,3-丁二烯”。

若双键在侧链上，侧链作为“烯基”取代基，例如乙烯基 —CH=CH2、烯丙基 —CH2CH=CH2。命名时仍以含主双键的最长链为母体，不能把烯基拆开。

6.3　环烯烃

环烯烃以环为母体，称为“环某烯”。编号时，双键的两个碳必须占 1、2 位，并沿双键方向编号，使取代基位次尽可能小。

例 6-3　环己烯与 1-甲基环己烯CYCLOALKENE
{{ fig('cyclohexene', '环己烯', 'small') }}
环己烯
{{ fig('1methylcyclohexene', '1-甲基环己烯', 'small') }}
1-甲基环己烯
读法：双键占 1、2 位；甲基在 1 位。若把甲基放在 2 位，名称会变成 2-甲基环己烯，但双键方向要重新编号，位次组会变大。

6.4　顺反异构初步

双键不能自由旋转，因此双键两端的基团可以固定在双键平面的同侧或异侧，形成顺反异构。判断条件是：双键的每个碳上都必须连有两个不同的基团。只要有一个碳连了两个相同的基团，就没有顺反异构。

有顺反异构

CH3CH=CHCH3：每个双键碳上都连 H 和 CH3，两个基团不同。

无顺反异构

(CH3)2C=CH2：左侧碳连两个相同的 CH3，无法区分顺反。

顺反的“顺”与“反”，是相对于双键平面而言：相同基团在同侧为顺，在异侧为反。对于 2-丁烯：

例 6-4　顺-2-丁烯与反-2-丁烯CIS / TRANS
{{ fig('cis2butene', '顺-2-丁烯：两个甲基在同侧', 'small') }}
顺-2-丁烯
{{ fig('trans2butene', '反-2-丁烯：两个甲基在异侧', 'small') }}
反-2-丁烯
读法：两个甲基在双键同侧为顺式，异侧为反式。若四个基团都不相同，顺/反就不够用了，需要 Z/E 标记（见第9章）。
顺反与 Z/E 的关系

顺/反只看“相同基团”的相对位置；Z/E 则按次序规则比较双键每个碳上的两个基团，取较优基团。对于简单的 2-丁烯，顺式就是 Z，反式就是 E；但对于取代基不同的烯烃，顺式不一定等于 Z，反式也不一定等于 E。第9章会专门讲这个易错点。

烯烃命名的“双低”
  • 双键位次低：从靠近双键的一端编号。

  • 主链一定含双键：不能为了“最长”而把双键丢在支链里。
